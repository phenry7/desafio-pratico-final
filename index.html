PROJETO FINAL • DEVOPS

Desenvolvimento,
Integração e Entrega.

Um projeto prático para demonstrar o fluxo DevOps, utilizando controle de versão, integração contínua e publicação de containers.

Conhecer tecnologias

terminal — devops

$ git push origin main

✓ Código enviado

$ podman build

✓ Imagem criada

$ podman push ghcr.io

✓ Publicação concluída

$ deploy --production

✓ Sistema disponível

FERRAMENTAS

Tecnologias utilizadas

Ferramentas aplicadas durante o desenvolvimento do projeto.

⌘

Git e GitHub

Versionamento de código, branches, commits e Pull Requests.

⚙

GitHub Actions

Automatização de tarefas e validação contínua do projeto.

▣

Podman

Criação e execução de containers para disponibilizar o site.

⬡

GHCR

Armazenamento e distribuição das imagens de containers.

OBJETIVO

Da programação à entrega.

O objetivo deste projeto é demonstrar na prática como organizar o desenvolvimento de software, automatizar verificações e distribuir aplicações utilizando containers.
